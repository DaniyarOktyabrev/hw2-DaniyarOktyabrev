# Домашнее задание 2: Продвинутая файловая система

## Реализованные расширения

### Метаданные
1. **modified_at** - время последнего изменения (обновляется при add, rename, modify)
2. **owner** - имя владельца (строка)
3. **tags** - список тегов (только для файлов)

### Методы
1. **list_paths(prefix="")** → list[str] - возвращает список полных путей до всех файлов
2. **tree(indent=0)** → str - красивый вывод структуры с вложенными отступами и размерами
3. **to_dict()** → dict - упаковка всех данных и метаданных в словарь

### Тестирование
Реализованы comprehensive тесты для проверки:
- Обновление modified_at при изменениях
- Корректность list_paths()
- Формирование tree() с размерами
- Рекурсивная работа to_dict()
- Работа тегов файлов
- Переименование и удаление
